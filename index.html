لوحة السيرفر (للقائد)

أونلاين

اختر إنشاء لوبي أو انضمام. LAN = شبكة محلية. Firebase = رومات وتزامن على الإنترنت فقط (الموقع نفسه على GitHub).

القائد: شغّل python lan_host.py — مع Radmin استخدم IP الشبكة الافتراضية

إنشاء لوبي

① اكتب رمز اللوبي

② عدد اللاعبين في الروم (شامل القائد)

3 لاعبين = أنت (القائد) + 2 أصحاب

③ ارفع ملف البيانات الشامل

④ اختار نوع الاتصال (مهم)

تبادل الأكواد (موصى به) = اتصال مباشر P2P — من غير بايثون ومن غير 127.0.0.1. LAN اختياري فقط لو عندك lan_host.

شغّل: python lan_host.py — مع Radmin حط IP شبكة Radmin (مثل 26.x.x.x). بدون نت.

شغّل: python lan_host.py ثم cloudflared tunnel --url http://localhost:27100 والصق الرابط هنا.

تبادل أكواد WebRTC (من غير بايثون):
⚠️ مهم: متفتحش index بالدبل كليك.
شغّل OPEN_GAME.bat عند كل واحد، والعب من http://127.0.0.1:8080/
(ده بس لفتح الصفحة محليًا — الاتصال بينكم P2P مش ماشي على السيرفر)
ابعتوا الأكواد كملف txt مش نسخ من الشات.

بعد التأكيد هتظهر شاشة تبادل الأكواد

انضمام للوبي

① نوع الاتصال

حط IP جهاز القائد (محلي أو Radmin مثل 26.x.x.x) — بدون نت.

الصق رابط trycloudflare بتاع القائد.

تبادل أكواد WebRTC (من غير بايثون):
1) اكتب نفس رمز اللوبي بتاع القائد (الملف الشامل اختياري)
2) بعد التأكيد الصق كود العرض اللي القائد بعتُه
3) هيتولد لك كود رد — ابعتُه للقائد
نفس الواي فاي أو Radmin — اتصال P2P مباشر وأقل بنج ممكن.

بعد التأكيد هتظهر شاشة لصق كود القائد

② رفع الملف الشامل (اختياري للمنضم)

القائد بيرفع الشامل. أنت تقدر تدخل من غيره — اللفل هيتبعت من القائد عند البداية. لو حصل مشكلة ارفع الشامل هنا.

يمكنك التخطي والاعتماد على مزامنة القائد

③ الرومات المتاحة / الرمز

اضغط تحديث بعد ما القائد يعمل لوبي

LAN يعتمد 100% على الشبكة المحلية — حتى لو مفيش نت. القائد يشغّل python lan_host.py
