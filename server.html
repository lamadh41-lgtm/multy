④ صاحبك على Radmin يدخل إزاي؟

  1. أنت وهو على نفس شبكة Radmin.
  2. تشغّل python lan_host.py وتفتح الصفحة دي.
  3. تختار IP Radmin من القائمة (غالبًا يبدأ بـ 26.x أو مشابه).
  4. تنسخ رابط المتصفح الأخضر وتبعتّه له (واتساب / ديسكورد).
  5. هو يفتح الرابط في المتصفح → أونلاين → انضمام → LAN/Radmin → نفس الـ IP + الرمز + نفس ملف ZIP.

نعم: لو بعتّله الرابط وهو على Radmin معاك، اللعبة هتفتح عنده ويتصل بسيرفرك.
