# Story Mode

## ملاحظة لأي AI / مطوّر

**كلمة «شامل» أو «الملف الشامل»** = ملف ZIP الذي يُحمَّل من زر **تحميل** في **وضع البناء** ويُرفع في **وضع المطوّر** / إنشاء أو انضمام الغرفة.  
هذا **ليس** حزمة تشغيل الموقع (`index.html` + `main.js`)، بل **بيانات المستويات** (بناء + سكربتات + أصوات + أغاني + صور).

التفاصيل الكاملة في: `READ_THIS_AI.md` (قسم 0).

---

## ملفات ZIP (النسخ)

ضع أي عدد من ملفات `.zip` بجانب `index.html`:

```
story-mode/
  index.html
  main.js
  packs.json
  الشامل.zip
  story-data.zip
```

اللعبة تكتشف الملفات وتعرضهم في قائمة عند إنشاء أو انضمام اللوبي.

### packs.json (مهم على GitHub Pages)

المتصفح لا يقرأ فولدر GitHub مباشرة، فسجّل أسماء الملفات هنا:

```json
[
  "الشامل.zip",
  "story-data.zip"
]
```

عند إضافة ZIP جديد: أضفه للفولدر + لـ packs.json.

### محلياً

مع سيرفر ملفات بسيط، قد تُكتشف ملفات ZIP من فهرس المجلد أيضاً.

## اللوبي

- القائد: رمز + رفع الملف الشامل + اختيار LAN أو كلاودفير → تأكيد
- المنضم: نفس نوع الاتصال + نفس العنوان + رفع نفس الملف + رمز أو قائمة الرومات

## الأونلاين (سيرفر القائد فقط)

زر **أونلاين** مربوط بالشخص اللي شغّال عنده `python lan_host.py`.

### هل وضع LAN محتاج lan_host؟

**نعم.** القائد يشغّل `python lan_host.py` حتى في LAN الخالص.
الفرق عن كلاودفير: أصحابك يتصلوا بـ **IP المحلي** أو **IP شبكة Radmin** بدون tunnel.
الكفاءة عالية زي ماينكرافت LAN لأن الترافيك يفضل داخل الشبكة (محلية أو Radmin).

### أفضل أداء: Radmin (موصى به)

1. نزّل وثبّت **Radmin VPN** على أجهزة الجميع.
2. اعمل شبكة واحدة وانضموا لنفس الشبكة.
3. على جهاز القائد:
   ```
   python lan_host.py
   ```
4. انسخ **IP Radmin** بتاع القائد (يظهر في Radmin أو في لوحة `server.html` أو في الطباعة في التيرمنال).
5. في اللعبة: أونلاين → إنشاء/انضمام → **LAN / Radmin** → حط الـ IP ده.
6. لما تحط الـ IP تظهر رسالة: **تم التعرف على وجود الخادم** لو السيرفر شغال.

ده أعلى إرسال وأقل بنج (أفضل من كلاودفير بكثير).

### إنشاء لوبي

1. أونلاين → إنشاء لوبي → رمز + رفع الملف الشامل
2. اختار:
   - **LAN / Radmin**: نفس الشبكة أو Radmin — حط IP المحلي أو IP Radmin أو `127.0.0.1`
   - **كلاودفير**: للصق رابط `https://xxxx.trycloudflare.com`

عند كتابة الـ IP/الرابط اللعبة تفحص الخادم تلقائياً وتعرض:
- ✓ تم التعرف على وجود الخادم
- أو رسالة خطأ لو مش واصل

### على جهاز القائد (LAN / Radmin)

```
python lan_host.py
```

أعطِ أصحابك IP جهازك (محلي أو Radmin — يظهر في لوحة السيرفر أو `ipconfig` / `ip a`) + رمز الروم.

### على جهاز القائد (إنترنت / كلاودفير)

```
python lan_host.py
cloudflared tunnel --url http://localhost:27100
```

انسخ الرابط وأعطِه للمنضمين.

### المنضم

- أونلاين → انضمام → اختار LAN/Radmin أو كلاودفير
- نفس العنوان (IP أو رابط) + رفع نفس ملف ZIP + اختيار الروم من القائمة أو كتابة الرمز
